# RenMonie v1.1

RenMonie is a clearly marked banking-app simulator for UI/UX testing. It is not connected to a bank and does not move real money.

## Included
- Dark modern banking dashboard
- Persistent simulator balance and transaction history
- Other Banks Transfer flow with simulated account verification
- Airtime/Data top-up UI
- Transfer confirmation and receipt
- History and transaction detail screens
- More/services screen
- RenMonie app icon and branding

## Build
Open the `RenMonie` folder in Android Studio and run the `app` configuration.


## RenMonie 1.2 upgrade

This build adds a local-only fintech UI upgrade:
- PIN verification before transfers, airtime, data and bill payments.
- Hashed transaction PIN storage with 3-attempt lockout and 30-second cooldown.
- Bills & Services screen for electricity, cable TV, internet, education and other services.
- Account & Login details screen.
- Theme & Appearance screen with seven colour presets.
- Animated successful transaction receipt/check mark.
- Existing wallet, transaction history, receipts and dashboard functionality retained.

The app remains a local prototype/simulation. Bill providers and banking rails are not connected to real financial networks.
